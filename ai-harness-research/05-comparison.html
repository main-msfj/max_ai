Comparison architecture

Architectural reading

Consistent core

All four expose some form of iterative turns, context, model call, tool registry/dispatch and result reinsertion. That is the minimum agentic spine.

Security differentiators

Codex makes the OS boundary explicit through sandbox modes and approvals. Claude exposes fine-grained tool/path rules and extension-level permissions. Agents SDK provides guardrails but delegates OS policy. Grok’s published runtime includes sandbox/workspace crates.

Context differentiators

Claude’s CLAUDE.md/skills/plugins/MCP control plane is unusually visible in the user model. Agents SDK makes sessions and input filters explicit. Grok and Codex expose repository/workspace state through source, but their current compaction details remain version-sensitive.

Unknowns matter

Closed or rapidly changing systems leave model routing, compaction algorithms, retry policy, verifier design and persistent memory schemas partially unknown. The symbols do not mean absence.

Common spine

Shared pattern: UI/CLI input → session/task state → context builder → model adapter → model tool call → permission/policy → executor/environment → structured result → session/transcript → next model turn. The main architectural differences are where policy is enforced, how state is persisted, and whether the runtime is closed, crate-based, or plugin-composed.

Ralph Loop

Ralph is best understood as a control-loop pattern: repeatedly observe state, build context, ask the model, execute actions, verify and persist. It is a slice of a harness, not a complete harness implementation.

INFERRED abstractionNo single canonical implementation assumed

Ralph Loop

while (!done) {   observe();   context = buildContext();   response = model(context);   executeTools(response);   verify();   persist(); }

What Ralph represents

Agent loop

Yes: the repeated turn/control structure.

Context management

Only as the abstract buildContext(); it does not define loading, pruning, compaction or trust boundaries.

Tool execution

Only as executeTools(); it does not define registry, schemas, dispatch errors or capability policy.

Verification

Names the phase explicitly, but leaves the verifier contract open: tests, compiler, assertions, reviewer or model self-evaluation.

Persistence

Names state durability, but does not define transcript format, checkpoints, sessions or external state reconciliation.

Stopping

!done implies a stopping condition, but budgets, cancellation and human interrupts must be designed separately.

What a full coding-agent harness must add

Capability Ralph placeholder Full harness responsibility
Permissions — Allow/deny/ask and policy evaluation before execution.
Sandbox — Enforce filesystem, network and process boundaries at OS/container layer.
Tool registry executeTools() Typed names, schemas, capabilities and versioned executors.
MCP — Discover/connect external tools and mediate their permissions.
Subagents — Spawn isolated context/runtimes and merge results.
Hooks — Pre/post model, tool and lifecycle interception.
Tracing — Record tokens, latency, tool calls, approvals and errors.
UI — Display progress, diffs, approvals, cancellation and resume.
Advanced context buildContext() Instruction precedence, retrieval, compaction, summarization and token budgets.
Useful mental model. Ralph is the temporal skeleton. A production harness is the skeleton plus typed boundaries, security enforcement, state semantics, verification evidence, extension points and observability.

OpenCode

Open-source coding agent with TUI/CLI, sessions, primary and subagents, granular permissions, built-in filesystem/search/shell tools, MCP, LSP, skills, plugins and provider adapters.

VERIFIED: official source/docsMITTypeScript / Bun monorepomulti-provider

Agent profiles

Build is the primary coding agent; Plan is restricted; General and Explore are subagent profiles. Agents combine prompt, model, tools and permissions.

Permission model

Rules are allow, ask or deny, keyed by tool with path/command patterns and per-agent overrides.

Tool model

read, edit/write/apply_patch, glob, grep, list, bash, task, webfetch/websearch, lsp, skill, question, todo and MCP/custom tools.

Exact execution flow

VERIFIED The UI/session layer selects an agent and model; the agent's permissions gate the tool; results are recorded in session state and become input to the next turn.

Component map

Runtime and sessions

The source tree exposes session, agent, server, storage, project and event modules. Sessions are the durable unit for conversation/tool state. VERIFIED

Context

Project rules, file references, command templates, skills and session history feed the model. Maintenance agents handle compaction/title/summary. VERIFIED

Tools

Built-ins cover read/edit/apply_patch, glob/grep/list, bash, task, webfetch/websearch, lsp, skill, question, todo; custom tools and MCP extend the registry. VERIFIED

Permissions

allow, ask, deny; auto mode approves except explicit denials. doom_loop and external_directory are safety guards. VERIFIED

Subagents

Primary agents invoke subagents through task/subagent; child sessions have fresh context and their own configured permissions. VERIFIED

Extensions

Plugins, MCP, skills, custom commands, LSP and lifecycle hooks are extension points. Pin the release when documenting exact event order. VERIFIED

Verification

INFERRED Tests/builds run via bash or custom commands; docs do not establish a universal independent verifier.

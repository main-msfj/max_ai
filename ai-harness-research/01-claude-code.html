Claude Code

A closed-source terminal coding agent whose public architecture is exposed through its CLI, configuration, permission model, lifecycle hooks, subagents, skills, plugins, MCP integration and Agent SDK.

Operate on a local codebase through model-directed reads, edits, shell commands and external tools.

Official links

Docs · SDK · no public source repository for the CLI.

2. Architecture overview

Anthropic documents the interaction contract and extension points, but not the internal classes. This is a public-surface reconstruction: the model proposes tool calls; the CLI mediates permissions and executes them; outputs return as new model input.

3. Component map

A · Agent Runtime VERIFIED

Interactive continuation, resume by session id, --max-turns, streaming output and permission modes are public. Exact internal loop and stopping classifier are UNKNOWN; observed behavior is an iterative model/tool loop.

B/C · Model + Context

VERIFIED Anthropic API by default; model selection and streaming JSON. The harness owns prompt assembly, history, tool schemas and instruction files. CLAUDE.md loads project/user guidance; skills are reusable prompt procedures. Exact compaction algorithm is UNKNOWN.

D/E · Tools + dispatch

VERIFIED Public built-ins include Read, Edit, Write, Bash, Glob, Grep, WebFetch, WebSearch, NotebookEdit, Agent and MCP tools. The model emits a call; permission rules and hooks allow, ask or deny; an executor returns output. Parser/dispatcher classes are UNKNOWN.

F · Environment

VERIFIED Local working directory, files, shell processes, git and network are used. Writes are scoped by policy; OS isolation is not supplied by the closed CLI itself. Anthropic recommends containers/VMs for stronger isolation.

G · Permissions / Security

VERIFIED Modes include default, acceptEdits, plan, auto and bypassPermissions; allow/ask/deny rules target tools and command/path patterns. Hooks provide deterministic pre-tool checks. Exact internal classifier is UNKNOWN.

H · Verification

INFERRED The harness exposes command output and tool results to the model; tests, builds and linters are executed through Bash. No public evidence of a universal independent verifier for arbitrary tasks.

I · State / Memory

VERIFIED Session continuation/resume and transcript state exist. CLAUDE.md provides persistent project/user instructions; filesystem and git are external state. A vector long-term memory is UNKNOWN.

J · Subagents

VERIFIED Agent creates isolated Claude instances with their own context windows and returns a result to the parent. Worktree isolation and nesting controls are documented.

K/M/N · Hooks, observability, human

VERIFIED Hooks fire at PreToolUse, PostToolUse, Stop and SubagentStop. Verbose mode, structured output and OpenTelemetry/metrics provide visibility. Human approval appears at permission checks and can interrupt/continue.

L · Extensions

VERIFIED MCP servers, skills, plugins, slash commands and custom subagents extend the core. Project-scoped .mcp.json servers require approval.

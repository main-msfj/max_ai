DeepSeek Harness

Harness oficial open source de DeepSeek. Su idea central es “everything is a plugin”: loop, sesiones, tools, sandbox, interacción humana y providers se componen mediante plugins Cordis.

VERIFIED: official sourceMITTypeScript / npm monorepoDeveloper preview

Harness vs model

DeepSeek Harness es el runtime. DeepSeek-V4 u otro provider aporta el modelo; no ejecuta filesystem, shell ni subagents por sí mismo.

Composition

Core/session/agent loop se combinan con fs, shell, terminal, code-runtime, web, MCP y subagent.

Safety

Interaction/permissions y sandbox están separados del loop y de los providers.

Exact execution flow

VERIFIED El repositorio oficial separa explícitamente core loop, sesiones, LLM, tool capabilities, sandbox, interaction y persistence.

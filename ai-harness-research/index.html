Reading the evidence

VERIFIED

Hay documentación oficial, código fuente público o una API oficial que demuestra el componente.

INFERRED

La relación arquitectónica se deduce de varios hechos, pero no está descrita literalmente por el proyecto.

UNKNOWN

No hay suficiente información pública para afirmarlo. “No identificado” no significa que no exista.

Build with Max AI#

Compose the capabilities your application needs from explicit, replaceable components.

Connect tools

Give an agent typed Python functions or native tools to use.

Remember users

Store user and session context with local, SQLite, or MongoDB memory.

Search knowledge

Retrieve relevant reference material only when the agent needs it.

Choose reasoning

Run an iterative reasoning loop that selects and uses tools.

Gate responses

Check a proposed answer before the agent returns it.

Track budgets and quotas

Set token, cost, time, and per-user usage limits.

Trace every run

Export traces for runs, model calls, and tool calls.

Run anywhere

Use local or remote workspaces and execution environments.

Installation#

Max AI requires Python 3.11 or later. The base package is client- and storage-agnostic; add only the extras you need.

Terminal
pip install maxai
pip install "maxai[cli,embeddings,tracing,mongodb,runtime-modal,azure-blob,minio]"
Terminal
uv add maxai
uv add "maxai[cli,embeddings,tracing,mongodb,runtime-modal,azure-blob,minio]"
ExtraAdds
cliThe Textual terminal UI (max_ai.cli.run_cli).
embeddingsLocal FastEmbedEmbedding for memory and knowledge search.
tracingOpenTelemetry export for tracing middleware.
mongodbMongoDB memory, knowledge, session, and quota stores.
runtime-modalSandboxed tool execution on Modal.
azure-blobAn AzureBlobWorkspace.
minioA MinIOWorkspace for MinIO or S3-compatible storage.

Using Ollama? Start the local server and download a model before running examples: ollama pull qwen3:8b. Max AI is Apache 2.0 licensed.

What's inside#

The Agent composes these parts. Every one is optional except identity and the model client.

RuntimeAgentStateless — one instance serves many users; runs of different (user_id, session_id) pairs execute in parallel. Agent reference →
ModelClientsOpenAI, OpenRouter, Ollama. Config stores the API-key env var name, never the key; output capped at 32K tokens. Clients →
ActionsToolsFunction tools, bash (allow/ask/deny), workspace files, plan, ask_user, and MCP (stdio/HTTP). Tools →
ContextMemory, knowledge, skillsLocal, SQLite, or MongoDB, searched by meaning with CoreEmbedding. Memory → · Knowledge → · Skills →
ControlReasoning, gates, compactionA ReAct loop, completion gates that can reject a final answer, and optional context compaction. Reasoning → · Compaction →
OpsMiddlewareLogging, per-task/per-user budgets and quotas, and OpenTelemetry tracing to Langfuse. Middleware →
StateSessionsThe host loads, runs, and saves a RunContext through a LocalSessionStore or MongoDB. Sessions →
HostCLIrun_cli(agent, store=..., user_id=..., session_id=...) — a terminal UI with approvals and resume. CLI →

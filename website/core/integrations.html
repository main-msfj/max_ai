Integrations

Connect external tools, return structured data, and handle approvals using the same agent runtime.

Connect MCP servers#

Pass remote server configurations through the Agent's mcp argument, separate from local Python tools in toolset. The agent connects servers, discovers tools, and dispatches calls; its managed MCP sessions close when the Agent closes. Server configurations are Pydantic models with JSON round-trip helpers.

MCP configuration · abbreviated
servers = [
    StdioMCPServerConfig(server_id="local-docs", command="your-mcp-server"),
    HTTPServerConfig(server_id="tickets", url="https://example.invalid/mcp",
                     token_env="TICKETS_MCP_TOKEN"),
]
agent = Agent(..., mcp=servers)

Replace the example server command and URL with real MCP endpoints. Use token_env for credentials; do not put literal tokens or sensitive headers into serialized configuration. MCP SDK support is declared in the repository's pyproject.toml.

Structured output#

Pass a Pydantic model class as output_format. The final assistant message carries the validated model instance, so application code can use typed fields directly.

Structured output · abbreviated
class Summary(BaseModel):
    title: str
    key_points: list[str]

agent = Agent(..., output_format=Summary)
response = await agent.run("Summarize the report")
summary = response.final_message.structured_output

The field constraints come from Pydantic. Use a model/provider combination that supports structured output for best results.

Approvals and resume#

Set a tool's approval mode to ask_for_approval. The run returns with pending approval records. A trusted reviewer can approve or reject the call, then the application resumes the same RunContext. User-input requests follow the same pause/resume pattern after the application stores an answer on the context's tool state.

Approval and resume · abbreviated
@tool(approval_mode="ask_for_approval")
def publish_report(report_id: str) -> str: ...

response = await agent.run("Publish report R-42")
if response.needs_approval:
    response.pending_approvals[0].approve(reason="Reviewed")
    response = await agent.resume(run_context=response.context)

This is the approval decision point in application code; connect the call to your actual review workflow. The agent returns AgentResponse with pending approvals and resumable run context.

Application interfaces#

The repository includes a Textual command-line interface. The runtime also exposes async APIs for streamed text, typed events, run cancellation, and resuming a serialized RunContext. The static documentation website is a separate Flask application under website/.

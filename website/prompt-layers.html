How a prompt
is assembled.

Prompt layers turn agent configuration and optional registry data into model instructions. They are rendered for each run, then adapted to the selected provider's message format.

03 · Variable sources

What gets injected into each layer?

The agent collects values before rendering. A layer only reads the names used by its own template; it does not query a registry directly.

TemplateVariablesSource
AgentPolicyLayername, description, instructionsAgent constructor
SkillsLayerloaded_skillsskills.get_skills() during prepare
KnowledgeLayerretrieval_toolsTool names from knowledge registries
MemoryLayerpersistent_memories, memory_toolsScoped memory registry
TaskAnalysisLayer—Static template text; no run variables
RenderingLayer—Static template text; no run variables
Not part of the prompt layers

The user task and chat history are CoreMessage entries in RunContext. Tool schemas are sent as the separate tools argument to the model client. Knowledge results are added as tool-result messages after retrieval.

04 · Template rendering

A variable becomes prompt text.

The template declares where a value belongs. At run time CoreLayer.render() inserts values into that position and returns a string. For example, AgentPolicyLayer has this structure:

Jinja2 template
<identity>
  <name>{{ name }}</name>
  <description>{{ description }}</description>
  <instructions>{{ instructions }}</instructions>
</identity>
Agent values
render into
the placeholders ↓
Rendered layer text
<identity>
  <name>math-assistant</name>
  <description>Answers questions with a calculator.</description>
  <instructions>Use the multiply tool when needed.</instructions>
</identity>

Templates use Jinja2. `CoreLayer` validates required and optional placeholders when it is constructed; strict rendering surfaces missing values instead of silently producing incomplete instructions.

05 · Injection point

Rendered layers enter the model client here.

The agent packages the ordered stack and its rendered strings in PromptCtx. The reasoning loop passes it into the client on every model call. The provider adapter decides how to form the actual request.

Agent._prompts() and BaseReasoning._call_llm()
variables = await self._prompt_variables(ctx)
prompts = PromptCtx(
    stack=self._stack,
    variables=variables,
    rendered_layers={
        type(layer): layer.render(variables)
        for layer in self._stack
    },
)

# ReactLoop supplies prompt context and tool schemas separately.
result = await self.client.run(
    ctx=self._model_context(ctx, transient_messages),
    prompts=prompts,
    tools=tools,
)

For Ollama, non-empty rendered layers are joined with blank lines into a system message. Conversation history and the current task follow as messages. Other model clients can assemble those pieces differently to match their provider APIs.

06 · Defining layers

Define a template and render it.

A CoreLayer subclass defines a template, its required variables, and optional variables. The framework's generic LayerContainer can hold layers and replace defaults.

Layer authoring · generic stack API
from max_ai.capabilities.stacks.agent_policy_layer import AgentPolicyLayer
from max_ai.core.stacks.container import LayerContainer
from max_ai.types.stacks import PromptCtx

policy = AgentPolicyLayer(
    template=(
        '<name>{{ name }}</name>\n'
        '<description>{{ description }}</description>\n'
        '<instructions>{{ instructions }}</instructions>'
    ),
)
variables = {
    'name': 'support',
    'description': 'A support assistant',
    'instructions': 'Answer with concise, grounded help.',
}
stack = LayerContainer([policy])
prompt = PromptCtx(
    stack=stack,
    variables=variables,
    rendered_layers={type(layer): layer.render(variables) for layer in stack},
)

Important: this demonstrates the generic layer and PromptCtx APIs. The current public max_ai.agents.Agent builds its stack inside _build_prompt_stack(); it does not yet accept prompt_layers= in its constructor. So a custom stack is not currently injectable into that Agent without extending the runtime.

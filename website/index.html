Installation#

Max AI requires Python 3.11 or later. From a local checkout of this repository, install the project and its dependencies.

Terminal 
uv sync
Terminal 
python -m pip install -e .

Using Ollama? Start the local server and download a model before running the examples: ollama pull qwen3:8b.

Your first agent#

An agent combines a model client with instructions and the tools it can call. These examples use a local Ollama model.

Define a typed function, register it with toolset, and let the agent use it to answer a question.

agent.py 
import asyncio
from max_ai.agents import Agent
from max_ai.capabilities.clients.ollama import OllamaChatCompletionClient
from max_ai.capabilities.tools.decorator import tool
from max_ai.core.model.llm import ModelConfig

@tool
def multiply(left: int, right: int) -> int:
    """Multiply two integers."""
    return left * right

async def main():
    # 1. Select a model client and declare its tool-calling support.
    client = OllamaChatCompletionClient(
        model="qwen3:8b",
        config=ModelConfig(supports_function_calling=True),
    )

    # 2. Compose the agent from its identity, client, and local toolset.
    agent = Agent(
        name="math-assistant",
        description="Answers simple questions with a calculator tool.",
        instructions="Use the multiply tool when multiplication is needed.",
        client=client,
        toolset=[multiply],
    )

    # 3. Run a task and read the final assistant text.
    async with agent:
        result = await agent.run("What is 19 multiplied by 23?")
        print(result.final_text)

asyncio.run(main())

The @tool decorator builds the input schema from your function. The agent handles registration and dispatch. Explore function tools →

Pass a Pydantic model as output_format to describe the result your application needs.

structured_output.py 
import asyncio
from pydantic import BaseModel, Field
from max_ai.agents import Agent
from max_ai.capabilities.clients.ollama import OllamaChatCompletionClient
from max_ai.core.model.llm import ModelConfig

class Summary(BaseModel):
    title: str
    key_points: list[str]
    confidence: float = Field(ge=0, le=1)

async def main():
    client = OllamaChatCompletionClient(
        model="qwen3:8b",
        config=ModelConfig(supports_function_calling=True),
    )
    agent = Agent(
        name="summarizer",
        description="Summarizes reports as structured data.",
        instructions="Return a concise, faithful summary.",
        client=client,
        output_format=Summary,
    )
    async with agent:
        response = await agent.run("Summarize the supplied report.")
        message = response.final_message
        if message and message.structured_output:
            print(message.structured_output.title)

asyncio.run(main())

What happens during a run?

  1. Build the contextThe agent assembles instructions, tools, and enabled context providers.
  2. Call the model and execute toolsThe reasoning loop requests a response and dispatches tool calls.
  3. Read the resultUse final_text or the structured output from the final message. The async context manager closes managed resources.

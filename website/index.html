02 · First working example

Build a small tool-using agent.

This complete example defines a typed Python tool, adds it to an agent, asks a question that uses the tool, then reads the final response. It uses the Ollama client; start Ollama and pull a tool-capable model before running it.

agent.py
import asyncio
from max_ai.agents import Agent
from max_ai.capabilities.clients.ollama import OllamaChatCompletionClient
from max_ai.capabilities.tools.decorator import tool
from max_ai.core.model.llm import ModelConfig

@tool
def multiply(left: int, right: int) -> int:
    """Multiply two integers."""
    return left * right

async def main():
    # 1. Select a model client and declare its tool-calling support.
    client = OllamaChatCompletionClient(
        model="qwen3:8b",
        config=ModelConfig(supports_function_calling=True),
    )

    # 2. Compose the agent from its identity, client, and local toolset.
    agent = Agent(
        name="math-assistant",
        description="Answers simple questions with a calculator tool.",
        instructions="Use the multiply tool when multiplication is needed.",
        client=client,
        toolset=[multiply],
    )

    # 3. Run a task and read the final assistant text.
    async with agent:
        result = await agent.run("What is 19 multiplied by 23?")
        print(result.final_text)

asyncio.run(main())

Here @tool builds a validated tool adapter from the function signature and docstring. The function is passed through toolset; Max AI handles registration and dispatch. The async with block closes the agent's managed execution resources.

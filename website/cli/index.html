Command line interface

The Max AI CLI is a full interactive terminal interface for an already configured agent. Use it to try an agent during development, explore its behavior, or work with it directly when you do not need to deploy an application.

run_cli#

Run the agent in your terminal. The CLI handles input, displays responses and thinking, and can save conversations through a session store. Install the optional cli extra to use it.

Signature
async def run_cli(
    agent: Agent,
    *,
    show_thinking: bool = True,
    initial_context: RunContext | None = None,
    store: CoreSessionStore | None = None,
    user_id: str | None = None,
    session_id: str | None = None,
) -> None:
cli_example.py
import asyncio

from max_ai.agents import Agent
from max_ai.capabilities.clients.openai import OpenAIChatCompletionClient
from max_ai.capabilities.session_store import LocalSessionStore
from max_ai.cli import run_cli

client = OpenAIChatCompletionClient(
    model="gpt-5.6-luna",
    api_key="YOUR_API_KEY",
)
agent = Agent(
    name="Assistant",
    description="A helpful assistant.",
    instructions="Answer clearly and briefly.",
    client=client,
)

async def main() -> None:
    async with agent:
        await run_cli(
            agent,
            show_thinking=True,
            store=LocalSessionStore("./sessions"),
            user_id="user_001",
            session_id=None,
        )

asyncio.run(main())

The CLI is a host for the agent: it does not require a deployed web service. Build your agent once, pass it to run_cli, and use the terminal to test or chat with it.

Parameters#

ParameterDescription
agentThe configured Agent instance to run.
show_thinkingShow thinking blocks when the CLI opens. Defaults to True; toggle at runtime with Ctrl+T or /thinking.
storeOptional session store. With LocalSessionStore, the CLI saves after each turn and enables /resume.
user_idIdentifies whose sessions are saved. Use the same ID when resuming that user's conversations.
session_idOptional ID to load a saved session at startup. Leave as None to start a new session; use /resume to choose one later.
initial_contextOptional existing RunContext. Pass it when the host already has the conversation context and wants the CLI to continue it.

run_cli is an async function and returns None when the terminal UI exits.

Interactive controls#

Send messages directly in the terminal. Use Ctrl+O or /verbose to show or hide verbose runtime events. Use /session to view the current session ID, /resume to continue a saved conversation, and /new to start another one. See the parameters above for how the session store and IDs work.

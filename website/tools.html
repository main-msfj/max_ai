Tools & dispatch

Give your agent actions with typed Python functions or a custom CoreTool. The registry and dispatcher connect model requests to your implementation.

Registry and dispatch#

Tools declare callable schemas. ToolRegistry indexes them, and ToolDispatcher validates parameters, applies approval rules, and routes each call either to a host adapter or through EnvironmentManager to the configured executor.

tools.py 
from max_ai.capabilities.tools.decorator import tool

@tool
def calculate_total(price: float, quantity: int) -> float:
    """Calculate the total price for a quantity of items."""
    return price * quantity

Functions as tools#

Decorate a function with @tool and pass the resulting object in the agent's toolset. Max AI builds the JSON schema from type hints, uses the docstring as its description, validates arguments, and invokes the function. Regular and async functions are supported.

tools.py 
from max_ai.capabilities.tools.decorator import tool

@tool
def calculate_total(price: float, quantity: int) -> float:
    """Calculate the total price for a quantity of items."""
return price * quantity

@tool(approval_mode="ask_for_approval")
async def reserve_item(sku: str, quantity: int) -> dict:
    """Reserve stock for an item."""
return await inventory.reserve(sku, quantity)

In the async example, inventory is your application's inventory service. The registration snippet assumes an imported Agent, a configured client, and an async function.

Decorated functions use auto_approval by default. Use approval_mode="ask_for_approval" when an action should wait for a person. Set a custom name or description with @tool(name="…", description="…"). Type the first parameter as ToolContext if the function needs run-specific dependencies.

agent.py · register and run 
agent = Agent(
    name="shop-assistant",
    description="Answers shopping questions.",
    instructions="Use calculate_total for purchase totals.",
    client=client,
    toolset=[calculate_total, reserve_item],
)

async with agent:
    result = await agent.run("What is 3 items at $12.50 each?")
    print(result.final_text)

Native tools with CoreTool#

Subclass CoreTool when you need direct control over the input schema and execution. Implement the parameters property and async execute() method. The dispatcher validates the call first; your implementation returns a ToolResult tied to the call ID.

tax_tool.py 
from typing import Any
from max_ai.base import CoreTool
from max_ai.base.tools import ToolContext
from max_ai.core.termination import CancellationToken
from max_ai.types.tool_call import ToolCallRecord, ToolResult
from max_ai.types.tools import ToolApprovalMode

class AddTaxTool(CoreTool):
    def __init__(self) -> None:
        super().__init__(
            name="add_tax",
            description="Add a tax rate to an amount.",
            approval_mode=ToolApprovalMode.AUTO_APPROVED,
        )

    @property
def parameters(self) -> dict[str, Any]:
        return {
            "type": "object",
            "properties": {
                "amount": {"type": "number", "description": "Pre-tax amount."},
                "rate": {"type": "number", "description": "Rate, e.g. 0.08 for 8%."},
            },
            "required": ["amount", "rate"],
            "additionalProperties": False,
        }

    async def execute(
        self,
        tool_request: ToolCallRecord,
        tool_context: ToolContext | None = None,
        cancellation_token: CancellationToken | None = None,
    ) -> ToolResult:
        amount = float(tool_request.parameters["amount"])
        rate = float(tool_request.parameters["rate"])
        total = round(amount * (1 + rate), 2)
        return ToolResult.success_result(tool_request.id, {"total": total})

Pass an instance to the agent with toolset=[AddTaxTool()]. Define inputs with JSON Schema and choose the approval mode in super().__init__(). Read application dependencies from tool_context.deps, and return ToolResult.tool_failure(tool_request.id, "reason") on failure. A regular CoreTool runs in the agent process; use CoreRuntimeTool when implementation must run through the configured isolated runtime.

The reasoning loop#

BaseReasoning is the extension contract; ReactLoop is the default implementation. It coordinates model calls, tool dispatch, streamed events, iteration limits, cancellation, and pause/resume state.

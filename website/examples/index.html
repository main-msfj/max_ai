Examples

Explore minimal Python examples. Each example has its own page with an explanation and the complete code.

Basic examples

Basic agent

Creates a minimal assistant backed by the OpenAI provider.

Ollama agent

Connects an agent to a model served locally by Ollama.

Function tools

Gives a financial assistant a compound interest calculator.

Tool approval

Requires approval before a tool saves a report to a file.

Sessions

Continues a conversation across separate runs.

Memory

Stores and reuses a user preference with local memory.

Knowledge search

Lets an assistant search local reference documents.

Structured output

Returns data validated against a Pydantic model.

MCP tools

Connects an agent to tools exposed by an HTTP MCP server.

Skills

Adds a repository skill to a writing assistant.

Streaming events

Prints an agent response as it arrives.

Middleware and tracing

Logs run activity and can emit traces through an OpenTelemetry provider.

Workspace files

Creates a file in a user-specific workspace.

Concurrent runs

Serves two users concurrently with one agent configuration.

Full agent

Combines tools, memory, knowledge, skills, and sessions in one assistant.

Advanced examples

Native tool

Implements a compound interest calculator as a native framework tool.

PostgreSQL memory

Shows a minimal memory backend stored in PostgreSQL.

PostgreSQL knowledge

Demonstrates a small PostgreSQL-backed knowledge registry for office notes.

Custom middleware

Observes when an agent run starts and finishes.

In-memory session store

Implements session persistence with a Python dictionary.

Custom prompt layer

Adds a reusable English style instruction to an agent.

Custom embedding

Provides a small teaching embedding implementation based on word counts.

Custom workspace

Stores workspace files in a local folder that represents an alternate backend.

Serialize an agent

Saves an agent configuration as JSON.

Deserialize an agent

Rebuilds an agent from previously saved JSON.

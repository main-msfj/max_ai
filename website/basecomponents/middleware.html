Middleware

The middleware contract provides optional hooks around runs, model calls, and tool calls.

Base class and optional hooks#

CoreMiddleware is a serializable component with optional lifecycle hooks. It has no abstract methods: every hook has a default implementation. Subclasses override only the hooks they need, such as changing a model request or observing a tool result.

CoreMiddleware · complete class API
class CoreMiddleware(ComponentBase[MiddlewareConfig]):
    """Override only the hooks you need; the defaults change nothing."""
    component_type = "middleware"

    component_schema: t.ClassVar[type[BaseModel]] = MiddlewareConfig

    @property
    def state_key(self) -> str:
        """Key of this middleware's run state. Override if you register two
            instances of the same class. The base class provides this behavior;
            override it only to customize it."""
        ...

    async def on_run_start(
        self, mw: MiddlewareContext, task: list[CoreMessage] | None,
    ) -> None:
        """A run starts. ``task`` is the new input, ``None`` on a resume. The base
            class provides this behavior; override it only to customize it."""
        ...

    async def on_final_response(
        self, mw: MiddlewareContext, message: AssistantMessage,
    ) -> AssistantMessage:
        """The answer the gates accepted; return it, changed or not. The base class
            provides this behavior; override it only to customize it."""
        ...

    async def on_run_end(self, mw: MiddlewareContext, response: AgentResponse) -> None:
        """The run ended (finished, paused or stopped). The base class provides this
            behavior; override it only to customize it."""
        ...

    async def on_run_error(self, mw: MiddlewareContext, error: BaseException) -> None:
        """The run crashed or was cancelled; the error is raised after this. The
            base class provides this behavior; override it only to customize it."""
        ...

    async def on_model_request(self, mw: MiddlewareContext, request: ModelRequest) -> ModelRequest:
        """Inspect or modify a model request before it is sent. The base class
            provides this behavior; override it only to customize it."""
        ...

    async def on_model_chunk(
        self, mw: MiddlewareContext, request: ModelRequest, chunk: ChatCompletionChunk,
    ) -> ChatCompletionChunk | None:
        """A streamed chunk; ``None`` drops it. The base class provides this
            behavior; override it only to customize it."""
        ...

    async def on_model_response(
        self, mw: MiddlewareContext, request: ModelRequest, result: ChatCompletionResult,
    ) -> ChatCompletionResult:
        """Inspect or modify a completed model response. The base class provides
            this behavior; override it only to customize it."""
        ...

    async def on_model_error(
        self, mw: MiddlewareContext, request: ModelRequest, error: Exception,
    ) -> ChatCompletionResult | None:
        """The call failed after its retries. Return a result to recover (e.g. from
            a fallback model) or ``None`` to let the error through. The base class
            provides this behavior; override it only to customize it."""
        ...

    async def on_tool_request(
        self, mw: MiddlewareContext, request: ToolRequest,
    ) -> ToolResult | None:
        """Before an approved tool runs. Return a ``ToolResult`` to answer in its
            place (the tool does not run), ``None`` to let it run. The base class
            provides this behavior; override it only to customize it."""
        ...

    async def on_tool_response(
        self, mw: MiddlewareContext, request: ToolRequest, result: ToolResult,
    ) -> ToolResult:
        """Inspect or modify the result returned by a tool. The base class provides
            this behavior; override it only to customize it."""
        ...

    def _to_config(self) -> BaseModel:
        """Return the middleware settings for serialization. The base class provides
            this behavior; override it only to customize it."""
        ...

    @classmethod
    def _from_config(cls, config: BaseModel) -> t.Self:
        """Create middleware from its validated configuration. The base class
            provides this behavior; override it only to customize it."""
        ...
MethodWhat it receives or returns
on_run_start(), on_run_end(), on_run_error()Observe run start, completion, pause, stop, or error.
on_final_response()Inspect or replace the final answer before it is returned.
on_model_request(), on_model_chunk(), on_model_response(), on_model_error()Inspect or change model requests, streamed chunks, results, or errors.
on_tool_request(), on_tool_response()Allow or short-circuit a tool call, then inspect or change its result.

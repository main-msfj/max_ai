Skills

The skill contract manages selected skill packages while leaving retrieval from a source to a subclass.

Base class and contract methods#

CoreSkillBase is the skill-source contract. The shared class selects skills, manages its cache, validates skill files, and loads their metadata. A subclass implements how one selected skill is obtained from its source.

CoreSkillBase · complete class API
class CoreSkillBase(CoreAgentCapabilities[BaseModel], ABC):
    """Abstract base class for skill registries."""
    def __init__(self, source: str | Path, skills: list[str]) -> None:
        """Initialize the skill registry. The base class provides this behavior;
            override it only to customize it."""
        ...

    async def prepare(self) -> None:
        """Download/cache selected skills and load metadata. The base class provides
            this behavior; override it only to customize it."""
        ...

    async def get_skills(self) -> list[SkillBlock]:
        """Return selected skill metadata. The base class provides this behavior;
            override it only to customize it."""
        ...

    def materialize(self, directory: WorkspaceDirectory) -> Path:
        """Install selected skills into the runtime skill directory. The base class
            provides this behavior; override it only to customize it."""
        ...

    @staticmethod
    def _scan_skill(root: Path) -> dict[str, str]:
        """Read the metadata file from a skill directory. The base class provides
            this behavior; override it only to customize it."""
        ...

    @staticmethod
    def _read_skill_manifest(target_dir: Path) -> dict[str, str]:
        """Load the registry manifest from its cache directory. The base class
            provides this behavior; override it only to customize it."""
        ...

    @staticmethod
    def _write_skill_manifest(target_dir: Path, manifest: dict[str, str]) -> None:
        """Write the registry manifest to its cache directory. The base class
            provides this behavior; override it only to customize it."""
        ...

    def _sync_skill(self, source_dir: Path, target_dir: Path) -> None:
        """Bring an already-materialized skill up to date with its source. The base
            class provides this behavior; override it only to customize it."""
        ...

    @abstractmethod
    async def _download_skill(self, skill_name: str, target_dir: Path) -> None:
        """Download/copy one selected skill from source into target_dir. A concrete
            subclass must implement this method."""
        ...

    @staticmethod
    def _validate_source(source: str | Path) -> str:
        """Validate and normalize the source parameter. The base class provides this
            behavior; override it only to customize it."""
        ...

    @staticmethod
    def _validate_skill_names(skills: list[str]) -> list[str]:
        """Validate the list of skill names. The base class provides this behavior;
            override it only to customize it."""
        ...

    @staticmethod
    def _validate_skill_dir(skill_name: str, path: Path) -> None:
        """Validate that a skill directory has the required structure. The base
            class provides this behavior; override it only to customize it."""
        ...

    def _read_skill_block(self, skill_name: str, skill_dir: Path) -> SkillBlock:
        """Read and parse a skill's metadata from SKILL.md. The base class provides
            this behavior; override it only to customize it."""
        ...

    @staticmethod
    def _parse_frontmatter(text: str) -> dict[str, t.Any]:
        """Parse YAML frontmatter from markdown text. The base class provides this
            behavior; override it only to customize it."""
        ...

    @staticmethod
    def _resolve_cache_root() -> Path:
        """Resolve and create the root cache directory for skills. The base class
            provides this behavior; override it only to customize it."""
        ...

    def _registry_key(self) -> str:
        """Generate a unique cache key for this registry instance. The base class
            provides this behavior; override it only to customize it."""
        ...
MethodWhat it receives or returns
_download_skill()Receives the selected skill name and its cache destination. Copies or downloads that skill package; the base class validates its SKILL.md afterwards.

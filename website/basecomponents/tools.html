Tools

The native tool contract describes model-visible inputs and defines how a tool executes.

Base class and contract methods#

CoreTool is the native tool contract. Each tool exposes a JSON Schema for its inputs and implements execution. The Agent uses the schema to describe the tool to the model, then passes a validated ToolCallRecord to execute.

CoreTool · complete class API
class CoreTool(ComponentBase[BaseModel], ABC):
    """Base class for all agent tools."""
    component_type = "tool"

    _JSON_TYPE_MAP: t.ClassVar[dict[str, type | tuple[type, ...]]] = {
        "string": str,
        "number": (int, float),
        "integer": int,
        "boolean": bool,
        "array": list,
        "object": dict,
        "null": type(None),
    }

    def __init__(
        self,
        name: str,
        description: str,
        version: str = "1.0.0",
        approval_mode: ToolApprovalMode | str = ToolApprovalMode.ASK_APPROVED,
        timeout_seconds: float = 300,
        max_retries: int = 3,
        read_only: bool = False,
    ):
        """Initialize the run-scoped context supplied to a tool. The base class
            provides this behavior; override it only to customize it."""
        ...

    @property
    @abstractmethod
    def parameters(self) -> dict[str, t.Any]:
        """JSON schema for tool inputs. A concrete subclass must implement this
            method."""
        ...

    def docker_ref(self) -> DockerToolRef:
        """Return the container reference for a tool that supports isolation. The
            base class provides this behavior; override it only to customize it."""
        ...

    @abstractmethod
    async def execute(
        self,
        tool_request: ToolCallRecord,
        tool_context: ToolContext | None = None,
        cancellation_token: CancellationToken | None = None,
    ) -> ToolResult:
        """Execute the tool Args: tool_request: Input parameters for this
            invocation. tool_context: Runtime context (run id, session id, deps,
            ...). cancellation_token: Token for cooperative cancellation. A concrete
            subclass must implement this method."""
        ...

    def validate_parameters(self, tool_request: ToolCallRecord) -> CoreToolParameters:
        """Validate input parameters against this tool's JSON schema. The base class
            provides this behavior; override it only to customize it."""
        ...

    def build_tool_definition(self) -> CoreToolDefinition:
        """Return a provider-agnostic descriptor of this tool. The base class
            provides this behavior; override it only to customize it."""
        ...

    @classmethod
    def _check_type(cls, value: t.Any, expected_type: str) -> bool:
        """Match value to JSON schema type. The base class provides this behavior;
            override it only to customize it."""
        ...

    def _get_validator(self) -> Draft202012Validator:
        """Lazily build and cache the JSON Schema Validator The base class provides
            this behavior; override it only to customize it."""
        ...

    def __str__(self) -> str:
        """Return the tool name for display. The base class provides this behavior;
            override it only to customize it."""
        ...

    def __repr__(self) -> str:
        """Return a readable representation of this tool. The base class provides
            this behavior; override it only to customize it."""
        ...
MethodWhat it receives or returns
parametersA JSON Schema object that defines the tool inputs available to the model.
execute()Receives the validated ToolCallRecord, optional ToolContext, and cancellation token. Returns a ToolResult.

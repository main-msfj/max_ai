14 · Integrations

Connect multiple MCP servers.

Keep remote capabilities in the mcp or mcp_servers list, separate from local Python toolset. The agent connects servers for a run, discovers tools, dispatches calls, and closes its MCP sessions afterward. Both server configs and the mixed server list are Pydantic models with JSON round-trip helpers.

mcp_config.py
import os
from max_ai.agents import Agent
from max_ai.capabilities.clients.ollama import OllamaChatCompletionClient
from max_ai.capabilities.mcp import (
    HTTPServerConfig,
    StdioMCPServerConfig,
    serialize_mcp_servers,
    deserialize_mcp_servers,
)

servers = [
    StdioMCPServerConfig(
        server_id="local-docs",
        command="your-mcp-server",
    ),
    HTTPServerConfig(
        server_id="tickets",
        url="https://your-mcp.example/mcp",
        token=os.environ["TICKETS_MCP_TOKEN"],
    ),
]

stored_json = serialize_mcp_servers(servers)
restored_servers = deserialize_mcp_servers(stored_json)

agent = Agent(
    name="support",
    description="A support assistant",
    instructions="Use connected tools when useful.",
    client=OllamaChatCompletionClient(model="qwen3:8b"),
    mcp_servers=restored_servers,
)

Replace the example server command and URL with real MCP endpoints. Keep tokens and sensitive headers in a secret store when persisting serialized configs. MCP SDK support is declared in the repository's pyproject.toml.

09 · Typed results

Ask for a structured response.

Pass a Pydantic model class as output_format. The final assistant message carries the validated model instance, so application code can use typed fields directly.

structured_output.py
import asyncio
from pydantic import BaseModel, Field
from max_ai.agents import Agent
from max_ai.capabilities.clients.ollama import OllamaChatCompletionClient
from max_ai.core.model.llm import ModelConfig

class Summary(BaseModel):
    title: str
    key_points: list[str]
    confidence: float = Field(ge=0, le=1)

async def main():
    client = OllamaChatCompletionClient(
        model="qwen3:8b",
        config=ModelConfig(supports_function_calling=True),
    )
    agent = Agent(
        name="summarizer",
        description="Summarizes reports as structured data.",
        instructions="Return a concise, faithful summary.",
        client=client,
        output_format=Summary,
    )
    async with agent:
        response = await agent.run("Summarize the supplied report.")
        message = response.final_message
        if message and message.structured_output:
            print(message.structured_output.title)

asyncio.run(main())

The field constraints come from Pydantic. Use a model/provider combination that supports structured output for best results.

10 · Human review

Pause, approve, and resume.

Set a tool's approval mode to ask_for_approval. The run returns with pending approval records. A trusted reviewer can approve or reject the call, then the application resumes the same RunContext.

approval_flow.py · inside an async application
from max_ai.capabilities.tools.decorator import tool

@tool(approval_mode="ask_for_approval")
def publish_report(report_id: str) -> str:
    """Publish a report through the application's publishing service."""
    return publisher.publish(report_id)

agent = Agent(
    name="publisher",
    description="Publishes reports after review.",
    instructions="Use publish_report when asked to publish.",
    client=client,  # configured model client
    toolset=[publish_report],
)
response = await agent.run("Publish report R-42")
if response.needs_approval:
    # Wait for your UI or service to obtain a reviewer decision.
    call = response.pending_approvals[0]
    call.approve(reason="Approved by the assigned reviewer")
    response = await agent.resume(run_context=response.context)

This is the approval decision point in application code; connect the call to your actual review workflow. The agent returns AgentResponse with pending approvals and resumable run context.

Capabilities

Workspaces, execution providers, and context registries supply capabilities around the core Agent. Configure only the providers this application needs.

Workspace and execution#

WorkspaceBase owns persistent user files and skill materialization. ExecutorBase runs executor-routed tools. EnvironmentManager manages sessions linking the two. Available executors are Local, Docker, and Modal; local execution runs on the host and is not a sandbox.

WorkspaceBaseEnvironmentManagerExecutorBase

Memory, skills, and knowledge#

Memory is scoped to a user and session. Skills provide instructions and resources. Knowledge registries expose retrieval tools. Context registries are also available as independent providers for context data. Each capability has provider implementations under max_ai.capabilities, with config models kept in _model.py.

Model providers#

Provider-specific clients translate framework messages, tool schemas, streaming, and usage data to the model service. Current client packages include Ollama, OpenAI, and OpenRouter.

capabilities/clients/ollamacapabilities/clients/openaicapabilities/clients/openrouter

Run outcomes#

Runs can finish normally or pause for approval or additional input, hit an iteration limit, be cancelled, or remain incomplete. AgentResponse exposes the finish reason, completion decision, final text, and pending approval state.
